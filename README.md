# 🌾 KrushiMitra

KrushiMitra is an AI-powered agriculture assistant built to help farmers access farming guidance, crop recommendations, weather information, and agricultural insights through a simple mobile application.

## 🚀 Features

- 🤖 AI-powered farming assistant
- 🌱 Crop recommendations and guidance
- 🍃 Plant disease detection
- ☁️ Weather information
- 💰 Mandi market rates
- 🏛️ Government schemes information
- 🌐 Multi-language support
- 📱 Modern and user-friendly interface

## 🛠️ Tech Stack

- Kotlin
- Android Studio
- Jetpack Compose
- Gemini AI API
- Room Database
- Retrofit

## ⚙️ Setup

### Prerequisites

- Android Studio
- Gemini API Key

### Installation

```bash
git clone https://github.com/RohanDawange/KrushiMitra.git
```

Open the project in Android Studio.

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Run the application on an emulator or Android device.

## 🎯 Purpose

KrushiMitra aims to bridge the gap between farmers and technology by providing AI-driven agricultural assistance and useful farming resources in one platform.
